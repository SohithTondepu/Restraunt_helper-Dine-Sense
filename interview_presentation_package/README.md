# Interview Presentation Package: Aspect-Based Sentiment Analysis & Restaurant Analytics

This package contains the complete, curated, and self-contained project assets organized specifically for interview demonstrations.

---

## Folder Structure & Contents

### `01_datasets_and_preprocessing/`
* **`Restaurant reviews.csv`**: Raw input dataset of restaurant reviews and ratings.
* **`preprocessing.py`**: Clean text normalization and clause tokenization pipeline.
* **`data_loader.py`**: Review ingestion, metadata extraction, and grouped stratified data splits.
* **`cleaned_reviews.csv` / `cleaned_reviews.parquet`**: Preprocessed and cleaned review corpus.
* **`modified_annotations_2000_corrected_mixed.csv`**: 2,000 food reviews human-annotated dataset (12,700 rows, including 6,104 eligible aspect-sentiment pairs with the 70% gold benchmark mix).
* **`modified_annotations_2000_human_annotated.csv`**: Identical verified copy of the mixed human-annotated training dataset.
* **`modified_annotations_2000_corrected_orig_backup.csv`**: Original untouched backup of the 2,000 annotations prior to the 70% gold mix.
* **`gold_aspect_annotated_650_benchmark.csv`**: The 650 expert-annotated gold standard benchmark dataset.
* **`gold_650_train_mixed_70pct.csv`**: The 70% stratified split (455 clauses) mixed into the training dataset.
* **`gold_650_test_remaining_30pct.csv`**: The pristine 30% holdout test set (195 clauses) with zero training contamination.

---

### `02_aspect_engine/`
* **`aspect_engine.py`**: Two-tier Aspect Classification Engine:
  * **Tier 1**: Sub-millisecond exact lexicon, keyword regex, and service-latency routing.
  * **Tier 2**: Dense semantic cosine similarity using `all-MiniLM-L6-v2` embeddings for implicit aspects and metaphors.

---

### `03_predicted_aspects_2000/`
* **`clause_evaluation_input_2000.csv`**: Extracted clauses from the 2,000 reviews formatted for aspect classification.
* **`predicted_aspects_2000.csv`**: Calibrated aspect predictions generated by the hybrid Aspect Engine across all clauses ($F_1 = 79.4\%$).

---

### `04_aspect_engine_evaluation/`
* **`aspect_engine_classification_evaluation.ipynb`**: Evaluation notebook benchmarking the Aspect Engine against reference annotations:
  * Micro/Macro Precision, Recall, and F1 across all 5 operational categories (`Food`, `Service`, `Price / Value`, `Ambience`, `General Experience`).
  * Exact match and Jaccard similarity distributions.
  * Qualitative confusion matrices and error analysis.

---

### `06_gold_650_benchmark_evaluation/`
* **`gold_650_benchmark.ipynb`**: Out-of-distribution evaluation notebook:
  * Loads classical models and fine-tuned DistilBERT from `saved_models/`.
  * Evaluates on the independent Gold 650 benchmark set under balanced prior shift.
  * Reports Accuracy (%), Macro-F1 (%), and Weighted-F1 (%), with normalized confusion matrices.
* **`saved_models/`**: Checkpoints for classical ML models and `distilbert_neutral_boosted/`.

---

### `07_analytics_app_and_pipeline/`
* **`app.py`**: Streamlit Analytics Dashboard built with Plotly Express:
  1. **Overview**: Eligible review volume, restaurant counts, aspect mention rates, and review-level sentiment distribution.
  2. **Aspect Analytics**: Aspect-specific sentiment shares, counts, percentages, and optional Beta-Binomial Empirical Bayes smoothing.
  3. **Time Trends**: Monthly sentiment trajectories on verified review dates with visible sample sizes ($N$) and small-sample alerts ($N < 10$).
  4. **Peer Comparison**: Objective side-by-side restaurant benchmarking for any aspect without arbitrary composite scores.
  5. **Descriptive Insights**: Factual observations derived strictly from computed metrics (no causal claims or business recommendations).
  6. **Review Explorer**: Traceability explorer with dual sub-tabs for unique review-aspect pairs and raw clause assertions.
* **`analytics.py`**: Core analytics aggregation engine implementing deduplication, conflict resolution (`Mixed` rule), denominator filtering, and Method-of-Moments Beta prior estimation.
